# Frontend Panaderia

Arquitectura basada en plantar-front:

- Next.js con carpeta src modular
- pages para rutas
- services para consumo de API
- store para estado global
- layouts para estructura visual
- configs para auth y tema

## Ejecutar

1. Copiar .env.example como .env.local
2. Instalar dependencias: npm install
3. Ejecutar: npm run dev

## Variables

- NEXT_PUBLIC_API_URL: URL base del backend, por defecto http://localhost:3001/api
